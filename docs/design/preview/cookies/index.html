Cookies used by this demo

This demo sets no cookies at all: no analytics, no advertising, no third-party tags. It does use browser storage on the device, which is not a cookie but is listed here for transparency.

Browser storage

coffeenator.profile (localStorage)Name, theme, appearance, companion, avatar and onboarding milestones. Until cleared.
coffeenator.stack (localStorage)Manually tracked AI subscriptions. Until cleared.
coffeenator.sources (sessionStorage)Imported context text. Cleared when the tab closes.
coffeenator.chat (sessionStorage)The current transcript. Cleared when the tab closes.

How to clear it

Use “Clear local data” in the app settings, or clear site data in the browser. Clearing removes preferences, the avatar, imported context and tracked subscriptions from the device. Original files and any real third-party account are untouched.

If cookies were introduced

A live service would ask for consent before any non-essential cookie, would work without it, and would let consent be withdrawn as easily as it was given. Strictly necessary cookies, such as a session cookie for sign-in, would be set without consent and named here.
